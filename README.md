# Kahve Falında Kuantum Bug Avcısı

## Giriş (Ciddiyetle Okunmalıdır)

Bu proje, insanlık tarihinin en büyük bilimsel atılımlarından biri olma potansiyeline sahiptir. Kahve telvelerindeki gizemli desenleri analiz ederek, henüz yazılmamış kodlardaki kuantum seviyesi bug'ları öngören devrim niteliğinde bir sistemdir.

**Uyarı:** Bu yazılım gerçek kahve falı bakmaz. Sadece bakıyormuş gibi yapar. Bilimsel geçerliliği: -42.

## Nasıl Çalışır?

1. Bir fincan kahve içersiniz (veya içmiş gibi yaparsınız).
2. Script'i çalıştırırsınız.
3. Rastgele, abartılı bug raporları üretilir.
4. Evrenin anlamını sorgularsınız.

## Kurulum

```bash
pip install -r requirements.txt  # Aslında hiçbir şey gerekmiyor ama ciddi duruyor
python kahve_fali.py
```
